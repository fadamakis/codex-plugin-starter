# Supplemental dependency licenses

Some npm archives omit the upstream license file. The build includes these reviewed copies when the corresponding bundled package needs them. A new version without a packaged or reviewed license text stops the build.

| Package | Source | Source blob |
| --- | --- | --- |
| `@cfworker/json-schema@4.1.1` | [Upstream MIT license](https://github.com/cfworker/cfworker/blob/main/LICENSE.md) | `85bcd787b59cba04d1c533d8b3b276e96465983d` |

`THIRD_PARTY_NOTICES.md` is regenerated from the actual UI and server bundle inputs. It includes complete license and notice texts rather than just SPDX labels.
